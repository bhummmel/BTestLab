# OPNsense & UniFi Network Architecture

## Overview

The OPNsense & UniFi Network Architecture project was developed to create a centralized, manageable and scalable network infrastructure capable of supporting self-hosted services, virtualization workloads, media platforms, automation systems and remote administration.

The environment combines OPNsense firewall infrastructure, UniFi switching and wireless networking, VPN services and centralized management platforms in order to provide secure connectivity, operational visibility and infrastructure flexibility.

The project prioritizes network reliability, centralized administration, security, observability and long-term scalability while providing practical experience with enterprise networking concepts and infrastructure design.

---

## Objectives

The primary objective of the project was to establish a modern network architecture capable of supporting a growing homelab environment while maintaining centralized visibility and administrative control.

Firewall infrastructure provides traffic management, network security and routing functionality for internal and external services.

Managed networking infrastructure improves operational visibility, simplifies troubleshooting and provides centralized device administration.

VPN services allow secure remote access to infrastructure resources without exposing management interfaces directly to the public internet.

The project also serves as a platform for experimentation with routing, network segmentation, firewall administration, monitoring and enterprise networking technologies.
