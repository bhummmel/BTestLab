# pfSense VPN & DNS Infrastructure

## Overview

The pfSense VPN & DNS Infrastructure project was developed to provide secure remote access, centralized DNS management and enhanced network control for the homelab environment.

The infrastructure combines pfSense firewall services, VPN connectivity, DNS management and network security controls in order to provide reliable access to internal services while maintaining visibility and administrative control over network operations.

The project prioritizes security, operational flexibility, remote accessibility and centralized network management while providing practical experience with firewall administration, VPN deployment and DNS infrastructure management.

---

## Objectives

The primary objective of the project was to establish a secure network edge capable of supporting remote administration and centralized DNS services.

VPN infrastructure allows administrators to securely access internal resources without exposing management interfaces directly to the public internet.

DNS services provide centralized name resolution for infrastructure systems, applications and internal services.

Firewall infrastructure enables network traffic management, security policy enforcement and visibility into communications throughout the environment.

The project also serves as a platform for experimentation with enterprise networking concepts, secure remote access technologies and infrastructure security practices.
