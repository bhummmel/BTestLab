# Rongta RP80 PoE Evaluation

## Overview

The Rongta RP80 PoE Evaluation project focused on researching, evaluating and integrating a network-connected thermal receipt printer into a self-hosted infrastructure environment.

The project examined the suitability of Power over Ethernet (PoE) thermal printing hardware for use within home automation, monitoring and infrastructure notification workflows.

The evaluation included hardware capabilities, network integration, PoE deployment considerations, printing reliability and compatibility with self-hosted platforms.

The project provided practical experience with network-connected peripherals, PoE infrastructure planning and device integration within a modern homelab environment.

---
