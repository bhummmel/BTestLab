# UniFi Network Application on Unraid

## Overview

The UniFi Network Application on Unraid project was developed to provide centralized management, monitoring and administration of network infrastructure through a self-hosted controller environment.

The infrastructure combines Unraid, Dockerized application deployment, UniFi network hardware and centralized management services in order to provide visibility and control over network operations from a single platform.

The project prioritizes centralized administration, infrastructure visibility, operational flexibility and self-hosted network management while providing practical experience with enterprise-style networking technologies.

---

## Objectives

The primary objective of the project was to deploy and maintain a self-hosted UniFi Network Application environment capable of managing network devices from a centralized interface.

Centralized network management simplifies device adoption, configuration management and operational monitoring across the infrastructure environment.

Containerized deployment improves recoverability, simplifies upgrades and allows the management platform to operate independently from dedicated controller hardware.

The project also serves as a platform for experimentation with enterprise networking concepts, network monitoring, wireless infrastructure management and centralized device administration.

The environment was designed to improve understanding of network operations while providing operational visibility throughout the homelab environment.
