# Jellyfin on TrueNAS SCALE Deployment

## Overview

The Jellyfin on TrueNAS SCALE Deployment project focused on designing, deploying and managing a self-hosted media streaming platform capable of organizing, transcoding and distributing personal media libraries across multiple devices.

The environment combines Jellyfin, TrueNAS SCALE, ZFS storage, media datasets and hardware-accelerated transcoding in order to provide a centralized entertainment platform without dependence on subscription-based media servers.

The project emphasizes local ownership, media accessibility, infrastructure scalability and self-hosted services while providing practical experience with storage management, application deployment and media infrastructure administration.

---

## Objectives

The primary objective of the project was to deploy a fully self-hosted media platform capable of serving movies, television content, music and other digital media throughout the homelab environment.

The environment was designed to support:

* centralized media management
* multi-device streaming
* media library organization
* hardware transcoding
* user account management
* self-hosted entertainment services

The project also served as an opportunity to gain practical experience with application deployment on TrueNAS SCALE and the operational requirements of media server infrastructure.

The architecture prioritizes local ownership, flexibility and long-term scalability.
