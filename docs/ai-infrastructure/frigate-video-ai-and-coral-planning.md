# Frigate Video AI & Coral TPU Planning

## Overview

The Frigate Video AI & Coral TPU Planning project focused on evaluating and designing a self-hosted intelligent video surveillance platform capable of performing real-time object detection, event analysis and automation integration.

The project involved researching Frigate, Google Coral TPU acceleration, camera infrastructure requirements, hardware sizing, storage planning and Home Assistant integration in order to build a privacy-focused video analytics environment.

The environment emphasizes local processing, automation integration, infrastructure scalability and reduced cloud dependency while providing practical experience with computer vision technologies and AI-assisted monitoring systems.

---

The primary objective of the project was to design a video surveillance architecture capable of performing local object detection without relying on cloud-based analytics services.

The project focused on:

* infrastructure scalability

The environment was designed to improve situational awareness while maintaining privacy and operational control.

## Coral TPU Evaluation

Google Coral TPU acceleration became a major component of the planning process.

The Coral accelerator is designed to offload machine learning inference workloads from general-purpose CPUs and GPUs.

Benefits include:

* reduced CPU utilization
* lower power consumption
* faster object detection
* improved scalability
* predictable performance

The project evaluated both USB and PCIe Coral deployment options in order to determine the most suitable infrastructure design.

Hardware acceleration was identified as a critical component for long-term scalability.
