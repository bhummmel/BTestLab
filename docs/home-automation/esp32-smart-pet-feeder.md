# ESP32 Smart Pet Feeder

## Overview

The ESP32 Smart Pet Feeder project focused on designing and deploying a self-hosted automated feeding system capable of dispensing pet food while integrating directly with Home Assistant and local automation infrastructure.

The project combines ESP32 microcontrollers, ESPHome firmware, sensor integration, automation workflows and centralized monitoring in order to provide reliable and remotely manageable pet feeding functionality.

The environment emphasizes automation, reliability, local control and infrastructure integration while providing practical experience with embedded systems, IoT development and Home Assistant ecosystem integration.

---

## Objectives

The primary objective of the project was to automate pet feeding while maintaining complete local control over hardware, scheduling and monitoring systems.

The environment was designed to provide:

* automated feeding schedules
* remote feeding control
* feeding verification
* Home Assistant integration
* local operation
* infrastructure monitoring

The project also served as an opportunity to gain practical experience with microcontroller development, sensor integration and embedded automation systems.

The design prioritizes reliability and pet safety while eliminating dependence on cloud-based feeding platforms.
