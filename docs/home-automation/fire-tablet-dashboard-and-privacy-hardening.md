# Fire Tablet Dashboard & Privacy Hardening

## Overview

The Fire Tablet Dashboard & Privacy Hardening project focused on repurposing low-cost Amazon Fire tablets into dedicated smart home control panels while minimizing privacy concerns and reducing dependence on Amazon cloud services.

The project involved dashboard deployment, application customization, network isolation, privacy hardening, service restriction and Home Assistant integration in order to transform consumer tablets into self-hosted infrastructure interfaces.

The environment emphasizes local control, privacy, automation accessibility and infrastructure ownership while providing practical experience with Android customization, network security and smart home interface design.

---

## Objectives

The primary objective of the project was to convert inexpensive consumer tablets into dedicated Home Assistant dashboards suitable for daily infrastructure management.

The project focused on:

* Home Assistant integration

* dashboard accessibility

* infrastructure visibility

The environment was designed to provide convenient access to automation systems while minimizing unnecessary data collection and external dependencies.
