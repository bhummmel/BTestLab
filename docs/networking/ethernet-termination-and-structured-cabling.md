# Ethernet Termination & Structured Cabling

## Overview

The Ethernet Termination & Structured Cabling project focused on designing, installing, terminating and validating network cabling infrastructure used to support self-hosted services, networking equipment, wireless infrastructure and future homelab expansion.

The project involved cable routing, connector termination, infrastructure planning, testing procedures and long-term network organization practices in order to establish a reliable physical networking foundation.

The environment emphasizes maintainability, reliability, scalability and operational consistency while providing practical experience with structured cabling standards and physical network infrastructure deployment.

The primary objective of the project was to create a reliable and organized physical networking infrastructure capable of supporting current and future homelab requirements.
