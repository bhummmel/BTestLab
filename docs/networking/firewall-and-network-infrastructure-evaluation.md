# Firewall & Network Infrastructure Evaluation

## Overview

The Firewall & Network Infrastructure Evaluation project focused on researching, testing and comparing multiple networking platforms, firewall solutions and infrastructure designs in order to determine the most effective architecture for a growing homelab environment.

The project involved evaluation of firewall platforms, managed networking solutions, remote access technologies, monitoring capabilities and infrastructure management approaches while balancing performance, security, operational complexity and long-term scalability.

The project provided practical experience with infrastructure planning, vendor evaluation, network architecture design and technology selection processes commonly encountered in enterprise environments.

---

## Objectives

The primary objective of the project was to evaluate available networking and firewall solutions before committing to long-term infrastructure deployments.

The evaluation process focused on identifying platforms capable of supporting:

* secure remote access
* centralized administration
* network visibility
* infrastructure scalability
* operational reliability
* long-term maintainability

The project also served as an opportunity to develop practical experience comparing competing technologies and making infrastructure decisions based on operational requirements rather than vendor marketing.

The environment was designed to support informed decision making for future infrastructure growth.

---

## Evaluation Environment

The evaluation process included analysis of:

* pfSense
* OPNsense
* UniFi networking infrastructure
* managed switching platforms
* VPN technologies
* DNS services
* monitoring platforms
* infrastructure management tools

The evaluation was performed within a self-hosted environment supporting automation services, media platforms, virtualization workloads and storage infrastructure.

The process focused on understanding how each platform would integrate into a larger operational ecosystem.

Technology selection should be driven by operational requirements rather than individual features alone.

Infrastructure observability significantly impacts troubleshooting efficiency and long-term maintainability.
