# SB8200 Internet Performance Troubleshooting

## Overview

The SB8200 Internet Performance Troubleshooting project focused on diagnosing and resolving internet connectivity and performance issues within a self-hosted homelab environment.

The project involved investigating throughput limitations, modem configuration, ISP connectivity, network infrastructure interactions and performance bottlenecks in order to restore expected internet performance and improve operational visibility.

The troubleshooting process provided practical experience with broadband networking, DOCSIS infrastructure, ISP diagnostics and systematic network performance analysis.

The project emphasized root cause analysis, structured troubleshooting and infrastructure validation rather than relying on hardware replacement alone.

---

## Objectives

The primary objective of the project was to identify the source of internet performance degradation and restore expected service levels.

The investigation focused on:

* internet throughput validation
* modem health analysis
* ISP connectivity verification
* network performance testing
* infrastructure dependency analysis

The project also served as an opportunity to gain practical experience with broadband troubleshooting methodologies and WAN infrastructure diagnostics.

The environment was designed to improve understanding of how internet connectivity issues affect dependent infrastructure services.
