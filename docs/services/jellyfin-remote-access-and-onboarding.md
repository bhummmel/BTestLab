# Jellyfin Remote Access & User Onboarding

## Overview

The Jellyfin Remote Access & User Onboarding project focused on extending a self-hosted media platform beyond the local network while creating a secure and user-friendly onboarding process for friends, family and remote users.

The environment combines Jellyfin, reverse proxy services, secure remote access methods, account management and user support procedures in order to provide a reliable streaming experience outside the home network.

The project emphasizes accessibility, security, usability and self-hosted service management while providing practical experience with public-facing services, user administration and infrastructure operations.

---

## Objectives

The primary objective of the project was to enable secure access to self-hosted media services from remote locations while maintaining control over infrastructure and user management.

The environment was designed to support:

* remote media streaming

* onboarding documentation
* client device support
* infrastructure scalability

The project also served as an opportunity to gain practical experience operating internet-accessible services and supporting non-technical users.
